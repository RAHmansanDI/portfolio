# Sandi Rahman — Manufacturing & Quality Portfolio

Standalone, responsive HTML/CSS/JS website designed for GitHub Pages or other static hosting.
This is a different design from Sabit Iqbal Maulana's portfolio.

## Files
- `index.html`: content and page sections
- `styles.css`: layout, styling, responsive breakpoints
- `script.js`: filter, mobile menu, image lightbox, zoom and navigation
- `assets/*.webp`: optimized images (with some sensitive serial/order information blurred)
- `assets/CV-Sandi-Rahman.pdf`: resume supplied by the user

## Run locally
Open `index.html` in Chrome or Edge, or run `python -m http.server 8000` and visit http://localhost:8000.

## Publish on GitHub Pages
1. Create a new repository, e.g. `Sandi-Rahman-Portfolio` (do not overwrite Sabit's portfolio).
2. Upload the **contents** of this folder to the repository root, not the folder itself.
3. In repository Settings > Pages, select Deploy from a branch and choose main / root.
4. Wait for GitHub Pages to display the public URL (usually `https://username.github.io/Sandi-Rahman-Portfolio/`).
5. Reload without cache (Ctrl+F5) if replacing a previous version.
